# Open Graph share images (1200 x 630)

Generated by `make-og.py` in this folder. Do not hand-edit the JPEGs; change the page or the script and rerun:

```
python3 site/assets/og/make-og.py            # everything
python3 site/assets/og/make-og.py boxer      # one slug
python3 site/assets/og/make-og.py --list     # dry run
```

A new `site/<breed>-dog-tags/` folder is picked up automatically: headline `<Breed> dog tags` from its H1 (short names in `SHORT_NAMES`), first saying card engraved on a bone tag using the same layout as the site builder, anodized colour cycled hot pink / sky / yellow / royal / green. Guides use their H1, split at the first `:`/`?` or `(` into headline + aside. JPEG q82 4:4:4, stepped down only if a file would pass 150 KB.

Wire-up: done. Every page's `<head>` carries `og:image` (`https://saltydogtags.com/assets/og/<slug>.jpg`), `og:image:width` 1200, `og:image:height` 630 and `twitter:card` `summary_large_image`, written by `tools/lib/shell.mjs` (generated pages) and `tools/polish-pages.mjs` (guides, roast, wall); the home page has its own tags. Pages without a picture of their own use `home.jpg` (roast, policies, privacy) or `sayings.jpg` (themes, single sayings, salty).
